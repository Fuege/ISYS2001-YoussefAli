# Module 08 - API

Completed workshop and lab ticket from the ISYS2001 Module 08 API activities.

- `1_financial_chatbot_gemini.ipynb` builds a financial education chatbot, creates `transactions.csv`, and adds a biggest-three-expenses report.
- `lab_ticket_stock_chart.ipynb` fetches daily AAPL data from Alpha Vantage and charts the closing price.

Open each notebook with its Colab badge. Create a [Gemini API key](https://aistudio.google.com/api-keys) and an [Alpha Vantage API key](https://www.alphavantage.co/support/#api-key), then add them as `GOOGLE_API_KEY` and `ALPHAVANTAGE_API_KEY` to **Colab Secrets** with notebook access enabled before running the API cells. Never paste keys into notebook code or commit them to GitHub. Run the lab's fetch cell once; the chart cell can be rerun from the existing `prices` DataFrame.

The pandas calculations were checked locally. Live Gemini and Alpha Vantage requests need your own keys, so the submitted notebooks have no saved API outputs or stock chart. The included sample `transactions.csv` is generated by the workshop data cell.
